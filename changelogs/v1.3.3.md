# Musique v1.3.3 - Genuine Bit-Perfect Lossless Audio

### What's New

- **Genuine Bit-Perfect Lossless Audio Engine**:
  - Integrated local lossless audio playback engine powered by `symphonia`, `cpal`, and `rodio`.
  - Supports 16-bit, 24-bit, and 32-bit **FLAC**, **PCM WAV**, and **ALAC** at sample rates up to **192 kHz**.
  - Direct hardware sample rate negotiation with Windows WASAPI / CoreAudio / ALSA.
  - Polyphase sinc resampling fallback if an audio endpoint cannot accept native high sample rates.
  - Zero lossy transcoding in the playback pipeline.
  - 4.0-second prebuffered ring buffer running on a dedicated audio worker thread for glitch-free playback.

- **Hybrid Spotify Catalog Matching**:
  - Automatically indexes local lossless directories into an embedded SQLite database.
  - Fuzzy title/artist matching automatically routes Spotify library playback to your local bit-perfect FLAC/WAV files when available, preserving lyrics, covers, and metadata.

- **Audiophile Signal Path Inspector**:
  - Interactive status badge in the player bar:
    - `HI-RES LOSSLESS` (Gold gradient for >16-bit or >48 kHz).
    - `LOSSLESS` (Cyan gradient for CD-quality 16-bit 44.1k/48k).
    - `320 KBPS` / `160 KBPS` (Clean neutral badge for Spotify / lossy streams).
  - Clickable Signal Path modal displaying exact codec, bit-depth, sample rate, bitrate, channel count, and DAC output format.

- **Lossless & Audio Quality Settings**:
  - Added dedicated Lossless settings section in Settings.
  - Local music folder picker and background library scanner.
  - "Prefer local lossless copies" toggle.
  - Hardware audio device capability detector.
  - "Play Local Audio File..." direct playback action.
